Connexion
Gestion Engins — Transferts & Débardage

Cet appareil n'a pas encore de compte : récupérez ceux créés par l'administrateur via le cloud (Supabase), puis connectez-vous.

Première installation : créez le compte administrateur qui créera les autres comptes et définira leurs privilèges. Configurez ensuite Supabase dans Paramètres pour partager les comptes et les données.

Comptes partagés entre vos appareils via Supabase (mots de passe hachés) · le compte administrateur reste local à son poste.
Identifiant oublié ? Effacez les données du site dans le navigateur pour repartir de zéro.
